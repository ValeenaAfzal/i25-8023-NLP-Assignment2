# i25-8023 NLP Assignment 2: Neural NLP Pipeline for BBC Urdu

Repository: https://github.com/ValeenaAfzal/i25-8023-NLP-Assignment2

DS 5007 Natural Language Processing, Assignment 2 (section DS-A). This continues the Assignment 1 BBC Urdu
pipeline: word embeddings (TF-IDF, PPMI, Skip-gram Word2Vec), BiLSTM sequence labelling (POS with softmax, NER
with CRF + Viterbi) and a Transformer encoder for topic classification. Everything is written from scratch in
PyTorch: no pretrained models, no Gensim, no HuggingFace, and no `nn.Transformer`, `nn.MultiheadAttention` or
`nn.TransformerEncoder`.

## Setup

Python 3.10+ with:

```bash
pip install torch numpy scipy pandas scikit-learn matplotlib arabic-reshaper python-bidi jupyter
```

`arabic-reshaper` and `python-bidi` only make Urdu labels render correctly in matplotlib figures (t-SNE plot and
attention heatmaps). A GPU is not needed; the full notebook runs on a laptop CPU.

## Reproducing each part

Open the folder as the working directory (the notebook reads `cleaned.txt`, `raw.txt`, `Metadata.json` and imports
from `src/` with relative paths) and run the notebook top to bottom:

```bash
jupyter nbconvert --to notebook --execute --inplace i25-8023_Assignment2_DS-A.ipynb --ExecutePreprocessor.timeout=-1
```

All randomness is seeded (`SEED = 42`). The parts depend on each other in this order:

1. **Part 0, setup and topic labels**: loads the three A1 files and assigns each article to Politics, Sports,
   Economy, International or Health & Society with a keyword score (writes `data/topic_labels.json`).
2. **Part 1, word embeddings**: builds the 10k vocabulary (`word2idx.json`), `tfidf_matrix.npy` with the top-10
   discriminative words per topic, `ppmi_matrix.npy` (window 5) with the t-SNE plot and neighbours, then trains
   skip-gram with negative sampling (d = 100, k = 5, K = 10, Adam 1e-3, batch 1,024, 10 epochs) and saves
   `embeddings_w2v.npy`; evaluates neighbours, 10 analogies and the C1-C4 comparison with MRR.
3. **Part 2, sequence labelling**: samples 500 sentences (100 per topic), annotates them with the rule-based POS
   tagger and the gazetteer NER tagger, writes the CoNLL files (70/15/15 split stratified by topic), trains the
   2-layer BiLSTM (frozen vs fine-tuned C3 embeddings, CRF for NER), evaluates (accuracy, macro-F1, confusion
   matrix, conlleval, error analysis) and runs ablations A1-A4 with 3 seeds. Needs `embeddings_w2v.npy` from Part 1.
4. **Part 3, Transformer**: builds 256-token article sequences, trains the from-scratch Pre-LN Transformer
   (4 blocks, 4 heads, d_model 128, AdamW 5e-4 with 50 warm-up steps + cosine, 20 epochs), reports accuracy,
   macro-F1, the confusion matrix and attention heatmaps, and compares it with a BiLSTM classifier.

`embeddings/ppmi_matrix.npy` is about 400 MB, over GitHub's 100 MB file limit, so it is git-ignored. It is part of
the zip submission and is regenerated by running Part 1.

## Notes

* POS and NER labels are silver labels produced by rules (lexicon + A1 lemmatizer/stemmer, gazetteer + title rules),
  so the BiLSTM scores measure how well the network learns and generalises those rules from context.
* The handout says "12 tags" for POS but lists 11 (NOUN VERB ADJ ADV PRON DET CONJ POST NUM PUNC UNK); those 11 are used.
